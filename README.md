# AlexGromer/.github

Default community health files for repositories under the `AlexGromer` account.

GitHub uses these files for any repository that does not have its own copy:

- `SECURITY.md`: how to report a vulnerability privately
- `CONTRIBUTING.md`: how to propose a change
- `CODE_OF_CONDUCT.md`: community standards
- `.github/ISSUE_TEMPLATE/`: bug report and feature request forms
- `.github/PULL_REQUEST_TEMPLATE.md`: pull request checklist

A repository can override any of them by adding its own file. Licenses are not inherited from
this repository; each project carries its own `LICENSE`.
